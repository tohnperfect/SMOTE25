The 37 SMOTE-family methods in our corpus of 76 papers, sorted by the class setting in which each paper actually generates synthetic data, with an account of how each one builds on SMOTE. All 37 were checked against their PDFs on 28 October 2026.

The reference: SMOTE (2002)

Every method is read against the rule of Chawla et al. (2002): for a minority seed x, pick a partner x_nn among its 5 nearest minority neighbours and create x + λ(x_nn − x) with λ ~ U(0,1). SMOTE fixes six steps in the simplest way (every minority point is a seed, equal points per seed, a uniform partner among 5 neighbours, uniform placement on the segment, no filtering afterwards, run once before training). What the categories show

  1. Most SMOTE-family methods generate only for two classes.

    {{NB}} of 37 are Binary only. {{BRED}}. A multiclass name in a dataset list therefore does not mean multiclass generation.

  2. Methods that handle several classes are recent.

    Multiclass only or Binary + Multiclass: {{P0}} methods from 2002 to 2009, {{P1}} from 2010 to 2017, and {{P2}} from 2018 to 2026.

  3. Few methods show both settings, and five never show two classes.

    {{NBM}} are Binary + Multiclass; {{NM}} are Multiclass only, although their rules would logically cover two classes. Several multiclass extensions of binary methods (ADASYN, KNNOR, QC-SMOTE, CISO) are described or named as future work but never run.

  4. The PDF check corrected how many methods relate to SMOTE.

    The steps changed were corrected for {{CHANGED}} of the 36 variants, mostly by adding steps the earlier coding missed. Papers changing each step: {{STEPS}}.

Decisions still open

Loyalty-SMOTE: Binary only or Binary + Multiclass?

It runs on 5 multiclass datasets, but only the smallest class is ever oversampled and results use binary metrics. Coded Binary only for now, following rule 1.

GLOS: Multiclass only or Binary + Multiclass?

Its only two-class run is a parameter-tuning demo on Sonar (Fig. 7), whose class count the paper does not state. Coded Multiclass only for now.

Decided: supplementary experiments count

Experiments reported only in a paper's supplement count, because they show what the method can do. GAMO is therefore Binary + Multiclass (its two-class runs are tabular, in the supplement).

OREM / OREM-M: one entry with two variants

OREM is run on two-class data and OREM-M on multiclass data; OREMBoost is run on both. Coded Binary + Multiclass for the paper as a whole.

NROMM: Core or Partial?

Seeds of the "trapped" type get points from an optimised embedding, not interpolation. Still coded Core.

SMOM: wrong PDF in Drive

The file named as the SMOM paper contains INOS. SMOM was coded from its supplement; re-check once the main PDF is in Drive.
