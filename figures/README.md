# figures/

Figures for the paper (PDF for vector graphics, PNG for raster), referenced by
file name only, e.g. `\includegraphics{taxonomy}` (`\graphicspath` is set in `main.tex`).

Planned: `timeline`, `taxonomy`, `prisma-flow`.

Every figure needs a `\Description{...}` (alt text, plain text, under 2000
characters, not a repeat of the caption). Captions go below figures.
